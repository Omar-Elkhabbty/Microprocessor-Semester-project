🌡️ Dual-Channel Microprocessor Temperature Monitoring & Data Logging System📌 Project OverviewThis project is an advanced Dual-Channel Microprocessor-Based Temperature Monitoring & Logging System designed as an academic semester project. The system continuously acquires ambient temperature readings from two independent sensor channels at regular time intervals, processes the data, and retains critical statistical metrics in memory.Equipped with an interactive user control panel (push-button triggers), users can instantly query and view real-time data as well as historical temperature statistics on an integrated display unit (LCD/7-Segment).✨ Key FeaturesDual-Channel Sensing: Simultaneously reads and processes temperature inputs from two distinct analog/digital temperature sensors.Periodic Sampling Engine: Automatic data sampling and logging executed at fixed timer intervals.Statistical Analytics & Tracking:📈 Daily Maximum Temperature: Tracks the highest temperature logged during the current 24-hour cycle.🏆 Overall / Memory Maximum Temperature: Stores the highest temperature recorded since memory initialization.📉 Daily Minimum Temperature: Tracks the lowest temperature logged during the current 24-hour cycle.🧊 Overall / Memory Minimum Temperature: Stores the absolute lowest temperature ever recorded in system memory.Interactive Control Panel: Dedicated push buttons allow the user to cycle through real-time telemetry and statistical reports instantly.Hardware Simulation & Prototyping: Complete schematics and software routines simulated using Proteus ISIS.🛠️ Hardware & System Architecture                       +---------------------------+

Hardware ComponentsMicroprocessor / Microcontroller Core: Handles signal processing, timer interrupts, and algorithm execution.Temperature Sensors (2x): Calibrated sensors (e.g., LM35/DS18B20) for dual-location monitoring.Analog-to-Digital Converter (ADC): Translates sensor voltage signals into digital readings.Push Buttons: Dedicated input controls for user interaction and statistic retrieval.Display Module: Visualizes channel readings, system modes, and queried statistical data.🎮 User Interface & Push-Button MappingThe system provides an intuitive interface triggered by push buttons:Button TriggerFunction / Displayed OutputButton 1Daily Maximum (T_max_day): Highest recorded temperature in the current 24h period.Button 2Memory Maximum (T_max_all): Absolute maximum temperature stored in memory.Button 3Daily Minimum (T_min_day): Lowest recorded temperature in the current 24h period.Button 4Memory Minimum (T_min_all): Absolute minimum temperature stored in memory.📁 Repository Structure.

🚀 Getting Started & SimulationClone the Repository:git clone https://github.com/Omar-Elkhabbty/Microprocessor-Semester-project.git
Open Simulation:Launch Proteus Design Suite.Open the schematic project file located inside the simulation/ directory.Compile Source Code:Load the firmware source files in your compiler (e.g., Keil / MPLAB / Atmel Studio / MASM).Build the project to generate the corresponding .hex machine file.Run Simulation:Double-click the processor model in Proteus and assign the compiled .hex file.Click Play to start the simulation and interact with the push buttons.🔮 Future Enhancements💾 Integration of non-volatile EEPROM memory for persistent historical data storage after power cycles.📡 Wireless telemetry transmission via Bluetooth or Wi-Fi (ESP modules) for remote monitoring.📊 Graphical user dashboard integration for real-time trend plotting and analytics.👤 AuthorDeveloped by Omar Elkhabbty as part of the Microprocessor Course Work.If you found this project helpful, please consider giving it a ⭐ on GitHub!
